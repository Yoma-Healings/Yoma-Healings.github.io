# Portfolio redesign preview

This branch contains a review version of the multidisciplinary portfolio for Harrison Ogheneyoma Onigba.

## Preview files

- `portfolio-preview.html` — homepage
- `projects.html` — detailed project case studies
- `experience.html` — experience, education and professional development
- `portfolio-preview.css` — shared responsive design
- `portfolio-preview.js` — mobile navigation and dynamic footer year

## View locally

1. Clone the repository and switch to `portfolio-redesign`.
2. Open `portfolio-preview.html` in a browser, or use the VS Code Live Server extension.
3. Navigate to Projects and Experience from the header.

## Review before publishing

- Confirm the contact email and LinkedIn URL before adding them.
- Confirm project descriptions, hardware configuration, status and evidence against the original project records.
- Add exact dates and organisation details for industrial experience where available.
- Add exact certificate titles, issuing bodies and dates for additional certificates.
- Add project photographs, diagrams, source links and measured results only when they are available and verified.

The preview is deliberately separate from the current published homepage. Do not merge this branch into the default branch until content and visual review are complete.
