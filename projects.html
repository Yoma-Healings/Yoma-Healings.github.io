EMBEDDED SYSTEMS · IoT · ENGINEERING PROTOTYPE

Smart Security Street Light

Project aim. Design a cost-conscious street-lighting concept that responds to ambient light and nearby movement, helping reduce unnecessary lighting while providing a security-alert function.

System concept

The prototype combines an LDR for day/night detection, a radar/motion sensor for presence detection, a microcontroller-based control system and an LED street-light load. The intended behaviour is to keep lighting reduced when appropriate and increase illumination when movement is detected at night.

Communication and alerting

The development direction uses an ESP32-based receiver and a Telegram bot notification workflow to send a security alert with the station identity. The exact communication and hardware configuration should be confirmed against the final tested build before publishing a circuit diagram.

SOFTWARE ENGINEERING · BACKEND WEB DEVELOPMENT

StudentHub

Project aim. Develop the backend foundation for a learning-management platform, using a structured server-side application rather than treating the project as a static interface.

Technical direction

The repository is built around Node.js and Express, with EJS views and database-related tooling. The learning focus includes routing, controllers, application structure, server-rendered pages and persistent data.

Engineering focus

Organising features into maintainable modules, understanding request/response flow, connecting application logic to data storage and progressively implementing user-facing platform capabilities.

DATA ANALYTICS · EXPLORATORY ANALYSIS

Workforce Layoffs Analysis

Project aim. Explore workforce-layoff data to understand how reported layoffs vary across time, companies, industries and locations.

Analytical approach

A data-analysis workflow can include data inspection, cleaning, handling missing or inconsistent values, exploratory queries and visual summaries to make patterns easier to interpret.

What the analysis can show

With appropriate data and validation, the project can help describe distributions and trends in the dataset. Observed associations should not be presented as proof of the causes of layoffs.

ELECTRICAL ENGINEERING · POWER ELECTRONICS

24V, 5kVA Inverter Project

Project aim. A departmental project focused on inverter-system design and the practical considerations involved in supplying AC loads from a battery-based DC source.

Engineering considerations

The work involved inverter and battery sizing, load assessment, wiring considerations and understanding how system voltage, power demand and battery capacity relate.

Technical learning

The project provided an opportunity to connect power-electronics concepts with practical system planning. Final component specifications, circuit topology and test results should be included only after checking the original project documentation.
